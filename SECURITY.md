# Güvenlik politikası

## Desteklenen sürümler

Padrosdown henüz erken geliştirme aşamasındadır. Güvenlik düzeltmeleri yalnızca en yeni `0.1.x` sürümü ve `main` dalı için hazırlanır.

| Sürüm              | Destek         |
| ------------------ | -------------- |
| En güncel `0.1.x`  | Destekleniyor  |
| Daha eski sürümler | Desteklenmiyor |

## Açık bildirme

Bir güvenlik açığını herkese açık issue, discussion veya pull request içinde paylaşmayın. Depoda GitHub Private Vulnerability Reporting etkinse **Security → Report a vulnerability** yolunu kullanın. Bu özellik etkin değilse depo sahibine GitHub profili üzerinden özel olarak ulaşın ve yalnızca güvenli bir iletişim kanalı belirlendikten sonra ayrıntıları gönderin.

Bildirimde mümkünse şunlar yer almalıdır:

- Etkilenen sürüm veya commit
- Etkinin kısa açıklaması
- Kişisel not içeriği içermeyen tekrarlama adımları
- Önerilen düzeltme veya azaltma yöntemi

API anahtarı, gerçek not içeriği ya da kullanıcının mutlak dosya yollarını bildirimlere eklemeyin.
